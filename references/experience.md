## 坑（勿重复）

- GitHub 直下 OTF 截断（file 仍识别）→ 必须 sfnt 校验；SemiBold/Bold 各截过 2MB。
- 参数字典键名拼错（minDAU/miniDAU）只有运行时炸 → 冒烟测试要全时间轴采样。

## 2026-10-26 补充

- 容器类组件高度公式必须按"内容起点 + (n-1)×行高 + 行半高 + 底垫"算，不能只算 n×行高——checkList 首版 66+n×62 高度里第 3 行底部超出边框 13px，用户截图抓到；公式改为 124+(n-1)×rowH+44 后三项全入框。
- 单元素场景（只有一张清单卡）会偏左上留白大：模板 s1 已改居中（x=600,w=720）并加底部 flowPath 填充，构图更稳。

## 2026-10-26 边界系统性审查 + 任意比例

- 文字组件一律过 fitText（缩字号到 60% 下限，仍超则省略号），容器高度按"内容起点+(n-1)×行高+底垫"算——checkList 越界是这两条缺一导致的实例；审查后 folder/时间轴卡/矩阵表头/进度环标签/代码行全部补上。
- timesLine 这类"卡外附加文字"必须显式传 y（timesY），不能 cy+R+固定偏移——固定偏移在别的画幅/位置直接穿到时间轴下面。
- 任意比例的最小实现：W/H 从 film.json 注入（lib.js 用 let）+ chrome 锚定 W/H + 窄画幅紧凑模式 + 内容坐标由分镜给——组件不用重写，只需横/竖两套默认坐标模板（new.py 已内置）。

## 2026-10-26 v0.3.1 三处画面修复

- punch 是"推近后停住"：z 常驻 1.2，场景内容坐标必须按放大后的位置校核（右缘≤1560、底≤816 避字幕带）——验证片 typeOn y=800 放大后 830-874 压进字幕带，是"文字下半没了"的真因。
- 用户播放器可能按 4:3 裁切显示 16:9 片子：内容贴边（>1440）在真片里没越界、在用户那里被切——安全区规则要抗 10% 裁切。
- 字幕基线 H-160（用户反馈 H-190 太靠上）；下移量要小（30px），不然撞时间轴。

## 2026-10-26 v0.3.2 音画同步（系统性修复）

- 两套时钟漂移是架构级 bug：音频按自然时长排、画面按整小节向上取整排，量化垫层逐拍累积——敦煌片尾口播比画面早 11.6s（实测漂移表 b1 2.62s → b9 11.61s）。用户体感"口播说完了几秒，画面才演到"。
- 修复=小节网格当唯一主时钟：voice.py place 把每句音频落位到 拍起点+0.35s 并重写 cues（字幕/duck 同源跟随），plan 自动落位、手改 beats 后重跑 place；只重混音不重渲画面。
- 落位 lead 0.35s 让场景入场动画（l≈0.1-0.3）略先于声音——"画面宁早勿晚"的句级版本。

- 火山 TTS 每句自带 0.1~0.3s 前置静音：voice.py say 已内置首尾静音裁剪（阈值 0.008/20ms 窗、保留 50ms 呼吸、幂等），cue 起点=真实开口点；验证 19/20 句开口误差 ≤80ms。
- 混音成品验证别用 mix 能量法（SFX/鼓点混在一起分不清），用分轨 voice.wav 测开口点才是权威。
- 字幕烧帧是隐形耦合：place 只重写 cues+重混音时，帧里的字幕还停在旧时间轴（用户实测第二轮抓到）——正确顺序 place → audio build → render --full → ffmpeg，一步不能省。
- 无 timeline 的片底部会裸出 ~125px 空白带（字幕带之下、画布底之上）：scaffold 已加自动进度轨（拍刻度+进度+游标）填底，像素验证轨道行从 0% → 3~9% 填充。
- 弱透明元素（6%~30% alpha 的幽灵数字/装饰线）在阈值 110 的边缘扫描里隐形：stepIntro 幽灵数字被 punch 推到 (-71,-41) 半个数字出画、卷轴线左右出界，全被漏过——check.py 新增 edges 低阈值(32)扫描才抓到；stepIntro 坐标已 punch 安全化（z=1.2 后仍在画内），装饰边框线也必须守 x≥180 安全区。
- 进度轨不能当万能默认：用户指出情绪/故事型不需要进度感。落为 film.json progress 三态 + 底部占用优先级（timeline > 轨 > 字幕贴底 H-92），判定规则进 storyboard.md。
- 贴底字幕(H-92)会落在场景装饰框（原本到 H-96）之外，框下形成风格断裂空带（用户红框抓到）；而框线画进场景层又会被 punch 推出画外——正解是 scaffold 加 FILM.frame chrome 钩子（不缩放、整片稳定），框线下延到 H-40 并上下封口。
- 字幕全宽渐变衬底带会在底部形成横向分割感（与框线/底边叠成一条条阶梯，用户两轮抓到）：改为只给文字本身加深色投影（两遍绘制：glow 18 阴影层 + 正常层），任何主题下都不成带。
- 具体实体名词必须专用实体：敦煌被批'僧人用 person 图标、画壁/文书/沙粒没有'——加 entities.js（参数化人物/崖壁洞窟/壁画墙/坐佛/卷轴展开/沙粒堆积），验收 6/6 形象；纪律写入 storyboard.md。
- 老项目的 index.html 不会自动带上新库：升级引擎后要检查项目脚本装载块（敦煌曾因此 decor/wipe 静默失效）。
- 纯描边线稿在视频尺度认不清（用户："一根线似的"）：双层解法=①phosphor duotone 实心双色集（108 个，icons.py --fill，按填充设计，base 深色层+detail 主色层按序渐显）②手绘件/静态核闭合子路径自动填充（accentDeep 45%）；cfg.style:"line" 可退回线稿。验收：图标四格+敦煌僧人/崖壁全部"实心饱满一眼可辨"。
- huashu 双库移植三招：TOON.flat 双色分面（clip→阴影→偏移高光→本色）；DG.hand 手绘抖动（密度化+值噪声，加 8fps boiling=逐帧手绘感）；DG.revealMask 笔刷揭开（之字遮罩逐行刷出）——drawObj/drawEntity 的 cfg.flat/wobble/motion:"brushReveal"，验收双色立体/手绘感/完整刷出全过。
