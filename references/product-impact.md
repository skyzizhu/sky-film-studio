# 高能商业宣传：以共同动作组织视听

适用于用户要求炫酷、速度、运动感、强色彩和动态大字的产品宣传。选择 `product / impact`。目标是让观众先被吸引，再看清产品如何创造价值，最终记住卖点。用户的产品与品牌资料优先于预设审美；亮色产品、软件和消费品不必一律做成黑底霓虹。

## 将目标落实到镜头

| 维度 | 制作选择 | 观看时核对 |
|---|---|---|
| 核心利益与创意母题 | 选一个可见的变化，例如更紧凑、展开、连接；提炼为反复变化的形状/轨迹/声音 | 去掉宣传词后，能否看懂卖点；抽象特效是否解释了产品 |
| 产品身份与形态 | 建立主视角、轮廓、部件和标识；特写与远景复用同一对象 | 不因切镜改变接口、尺寸关系、结构或 UI 状态 |
| 叙事与情绪 | 钩子、蓄力、爆发、功能证据、呼吸、记忆收束按内容排列 | 中段有推进，高潮有反差，最后留下产品而非只有特效 |
| 景别与尺度 | 微距与全貌交替；一次特写只突出一个关键细节 | 观众能从细节回到完整产品，避免全片同尺度悬浮转圈 |
| 相机与空间 | 推近、掠过、绕行、穿越有路径和目标；必要时用稳定镜头演示操作 | 运动能引导视线；不会因持续旋转看不清功能 |
| 运动力学 | 起势、加速、惯性、制动、落定；通过物件质量选择曲线 | 速度感来自位移和时间变化；重物不随意橡皮弹跳 |
| 纵深与遮挡 | 前景掠过、中景产品、背景视差；利用产品边缘或文字作遮罩 | 遮挡关系正确，穿越不是穿模；主轮廓有辨识度 |
| 材质与表面 | 按实际材料组织粗糙度、反射、细节和接触阴影 | 金属、玻璃、塑料有区别，质感不靠一层泛光代替 |
| 灯光与显露 | 轮廓光建立悬念，方向光显露形体，局部扫光引导细节 | 暗处仍能辨形，高光不吞接口；灯光变化跟镜头有关系 |
| 色彩与段落 | 选择主色、对比色和中性色；在揭示/转折时有意改变色场 | 鲜明但保持层次；不因炫彩破坏真实产品和品牌色 |
| 画面主文字 | 卖点压缩成可记忆的短语；超大字、分词、透视、遮罩、前后景交错 | 文字是一段动作的主角，落定后能读；完整口播另走字幕层 |
| 转场与连接 | 匹配轮廓、方向、颜色、部件或文字；甩镜/遮挡切换只承担明确连接 | 切点两边有联系，视线落点接得上；不靠闪白隐藏不连续 |
| 特效与速度纹理 | 局部拖影、光线、粒子、折射或爆发围绕一个主动作设计 | 效果随动作产生并消失，停留画面干净；不持续全屏叠效果 |
| 音乐与能量 | 先编排蓄力、释放、休止、再推进；低频、节拍、主奏逐段进入/退出 | 音量大不等于有力量；高潮前有空间，片尾有乐句收束 |
| 音效与声音空间 | 运动用方向声，碰触用材料声，文字落点用短重音；按用途层叠低频/中频/空气感 | 主重音与关键动作同源，尾音不糊；不每次切换都同一种 whoosh |
| 视听同步与节奏 | 让相机落定、字形组合、产品揭示与一个音乐落点共同完成 | 不强制所有东西每拍都动；语义结果能看清，不只对齐节拍 |
| 品牌记忆与行动 | 反复使用少数形状、颜色或动势；片尾保留产品、核心利益与合法入口 | 观众记住是什么、为何有用；不补造品牌音标、参数或 CTA |
| 画幅与交付观感 | 按目标平台重排景别、主字和片尾；检查压缩后的细线/暗部/快速运动 | 手机缩小观看仍辨识主体，文字不出界，运动不被编码拖糊 |

这是一组相互配合的决策，不要求每片使用所有效果。每段选择一个主动作和少量辅助元素，给它足够的视觉对比。可用深色科技、明亮运动、液态流动、材质精密等不同艺术方向；预设的深底荧光色仅是起点。

## 分镜先写共同动作

在项目 `storyboard.md` 的每镜记录下列内容，作为实际制作依据，而非只写“高级、炫酷”：

| 时间/角色 | 卖点及依据 | 产品/相机动作与落定 | 灯光/颜色/空间 | 主文字动作与可读停留 | 出镜连接点 | 音乐能量、音效事件与落点 |
|---|---|---|---|---|---|---|
| 局部揭示 | 形态或材质，来源为产品参考 | 轮廓特写沿表面掠过，转为全貌 | 轮廓光后主光显露 | 短语随遮罩展开并落定 | 轮廓方向匹配下一镜 | 蓄力后 reveal；光线与声音同向 |
| 功能证据 | 一项实际操作或输出 | 稳定观察操作，结果完成后停留 | 降低干扰，明确操作区 | 卖点与结果关联，避开 UI | 沿部件或输出接出 | 降音乐密度；contact 跟随真实接触 |

风格镜头可以快，证据镜头必须足够清楚。可从 0.25–0.8 秒的短冲击、1–3 秒的动作与观察、2–4 秒的片尾尝试，按实际文字、口播和产品复杂度调整；这些不是品牌规范或强制镜长。整片时长仍遵守 SKILL.md。

镜头语法可以采用“准备 → 加速 → 遮挡/匹配切点 → 延续方向 → 落定”。要有意图地硬切也可以，但不要让每个段落都重新开始、重新飞入、重新播放同一个提示音。物理操作和示意变形分别处理；产品变形转场不得被误读为真实功能。

## 先做代表性片段，再铺全片

先制作包含产品揭示、一个高动势转场、一次主文字动作和一次结果落定的片段，并配实际音乐与音效。它用于校准此产品的广告语言；不把单张封面或预设颜色表当作风格验证。验证片段可短于整片，但明确标注为局部验证，不当作完成的短片交付。

检查顺序：静帧查形态和文字；正常速度片段查速度、落定和视线连接；有声片段查能量与同步；缩小到目标观看尺寸再查信息辨识。按完整音画播放的实际结果修正，无法播放/试听就明确记录限制。自动确定性、响度与边界检查只能验证技术部分。

有任一情况就回改：产品始终难辨、卖点只靠口号、快切导致文字来不及读、转场反复打断方向、音乐全程同强度、拖影覆盖 UI、光效掩盖形体、结果尚未发生就给成功音。改后重看相关动作前后及其声音，不能只检查孤立的落定帧。

## 配置和工具的边界

`--variant impact` 提供深色强反差配色、900 字重、128 BPM 小调和更强的低频/打击起点；它不会自动生成上述分镜、3D 材质、动态大字、配乐结构或商业广告效果。显式配置优先，已有项目不会自动重制。沿用 `ProductMotion.track/type` 编排绝对时间姿态与测宽文字；快速主体可局部使用 `trail`（见 product.md），停留和信息阅读区域保持清晰。

声音使用已提供的 launch_hit、air_sweep、ui_tick 或授权录音，通过显式事件编排；颜色、字形、声音和镜头的同步时点来自同一语义事件。music.sections/逐拍层次和 focus_events 可用于细节段减法，不把更高 BPM 当作完整的能量设计。最终混音仍遵守响度/真峰值要求，不以削波增加冲击。

需要真实复杂外形、玻璃折射、金属反射或摄影级光影时，使用用户授权实拍、匹配参考的素材或合适的 3D 渲染，再按同一时间轴合成。原始平面几何即使加拖影与高光，也不能宣称已经达到写实商业 CG。软件宣传优先展示真实操作，让功能结果与动效大字互相支持。
