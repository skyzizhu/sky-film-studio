# 产品宣传与展示

使用独立任务 `promotion` 组织卖点与证据，`product` 默认采用 impact 高能商业宣传，强调产品、镜头、灯光、动效大字与声音共同形成速度和冲击；可用 studio 保留安静陈列。两者可与其他内容/风格组合：工程产品可用 blueprint 解释机制，软件可保留真实界面。

```sh
python3 engine/new.py /absolute/new-film --content product --task promotion --style product --variant impact
```

高能商业宣传的多维设计、逐镜制作与观看验收见 [product-impact.md](product-impact.md)。现有 Canvas 投影与合成音乐支持风格示意；需要商业级材质或复杂真实产品时选用合适的授权素材/3D 管线，不能将平面高光称为写实渲染。

## 产品与观众

从用户资料提取目标观众、使用场景、一个核心利益、可展示的关键操作和行动入口。已有授权与品牌素材沿用；只有缺失信息影响实际宣传主张时才问。没有指定真实产品时，风格验证可用明确标注的概念产品，不能补造实际品牌、售价、认证、销量或性能。

- 实体：优先真实参考图/授权素材，核对轮廓、按钮、接口、材质、包装和标识。Canvas 简化展示注明示意；绘制高光不冒充摄影或物理渲染。
- 软件：优先已提供的真实界面与操作路径；模拟 UI 持续标识，不能用装饰数字证明性能或假装功能已经上线。录屏、截图、演绎与实际输出的选择，以及结果式开场、连续功能演示、景别与口播节奏，见 [product-proof.md](product-proof.md)。
- 卖点：主要利益对应实际操作、输出或可追溯的依据。性能对比写明设备、版本、数据集或测试条件；无法证实的比较删除或改为中性演示。

## 镜头关系

整体轮廓与身份 → 一个关键操作 → 看得见的结果 → 品牌/行动入口。按文稿调整，不强制四镜或固定节奏。一次特写突出一个部件；动作完成后保留观察时间，再换卖点。结果、字幕和品牌名不同时争主焦点。

通过轮廓、部件连接或操作结果衔接；镜头推进不让比例、标识或 UI 状态突然改变。明确对照可以硬切。使用 MaterialFX.sweep 时裁切到表面，避开品牌/文字/屏幕；粒子和扫光按镜头目的添加，不让装饰遮住产品。末尾保留可读的行动入口，只使用已提供或已核实的链接/二维码。

## 声音

默认 impact 使用 128 BPM 小调 product_pulse，增强低频与打击起点，细节段弱化，结尾收束；蓄力、留白和爆发仍需逐段编排，改 BPM 不会自动生成广告配乐。studio 使用原 product_clean 稀疏配乐。product_launch 声音档案提供发布重音、轻触与短提示，但只在显式事件上发声，不按每个切点自动添加音效。材料声按实际产品覆盖，软件按钮无声也可以成立。品牌声音标识使用用户素材，不能把通用 chime 当作其真实标识。

关键结果可用 `music.focus_events` 适度压低 BGM，接口见 [direction.md](direction.md)。它不改变口播或动作声。用同一片段做声音对照，再试听首句、操作接点和片尾；技术通过不代表宣传效果或品牌匹配已验收。

## 验收

核对真实产品/概念示意、主张来源、实际演示结果、品牌一致性、字幕和行动入口可读性。evidence 记录 subject/change/result 与事件引用；结构检查不证明卖点真实。默认 30–300 秒范围沿用本技能；更短广告需明确调整范围，不能默默输出契约外文件。

## 动态发布的可选处理

| variant | 构图与运动 | 配乐起点 |
|---|---|---|
| impact（默认） | 深色强反差起点、动效大字、尺度变化与惯性；按卖点重设品牌色 | 128 BPM，小调，增强低频/打击与细节段反差 |
| precision | 微距到全貌、准确落定、少量大字 | 120 BPM，短促主奏与低频节拍 |
| flow | 轮廓/材质连接镜头、连续空间轨迹 | 116 BPM，更连贯的音层 |
| playful | 大字与产品角度共构图、色块和遮罩 | 124 BPM，错落音型与休止 |
| studio | 稳定全貌、慢速局部观察 | 100 BPM，原安静陈列乐句 |

它们是本技能的设计方向，数值不是任何品牌的固定规范。参考来源及本轮研究边界见 [product-references.md](product-references.md)。一个项目选主方向，再按内容调整；不把三家公司片段机械拼在一起。选择指导会写入 direction-plan，但不会替作者完成镜头。显式 BPM、音乐、颜色仍优先；换旧片方向时先看覆盖项，不宣称改了名字就完成风格转换。

- 节奏：用快起减速、尺度对比与短镜头推进，给产品识别、操作结果和行动入口留清楚的落定段。不是全片匀速旋转，也不要求每一秒换景。不要用短字卡承载观众来不及读的完整口播。
- 衔接：轮廓、运动方向、部件或颜色关系用于匹配切换；同一产品的真实形态与机制状态继续保留。明确的全貌/微距切换可以硬切，不能用闪白掩盖穿插。
- 声音：launch_hit 用于少量揭示/收束，air_sweep 用于有方向的快速运动，ui_tick 用于明确的小事件；全为合成示意。声音数量按动作需要决定，不强制每镜 whoosh。
- 字体：随项目快照的 Noto Sans SC 可变字体用于现代中文大字，含 OFL 与来源；用户品牌字体优先。未变更旧项目字体。

## 动作与文字接口

new.py 自动加载 vendor/product-motion.js。运动由绝对时间求值：

```js
const pose=ProductMotion.track(t,[
 {at:0,x:1100,y:700,scale:2.4,rx:.5,ry:-.4},
 {at:.8,x:960,y:700,scale:1.5,ry:.2,ease:'arrive'},
 {at:2,x:960,y:700,scale:1.5,ry:.2}
]);
ProductMotion.type(ctx,t,[.2,.75],'打开，有序。',
 {x:100,y:250,size:110,maxWidth:1500,color:FILM_META.product.ink});
```

track 返回 x/y/scale/rx/ry/rz/opacity；角度为场景约定的弧度，缺字段继承前值，时间前后保持端点。到达后一帧的 ease 控制该段：arrive 快起缓停，smooth 两端平滑，linear 匀速。相同相邻姿态形成停留，不累积帧状态；姿态本身不替场景绘制产品或求解机械结构。type 按实测文字宽度缩放字号，在局部遮罩内入场，保留完整文字并恢复上层 alpha/变换。

同一阅读区的原文/译文、波形/字幕可用顺序替换，周围卡片和主体保持在回调之外：

```js
drawPersistentCard(ctx,t);
ProductMotion.replace(ctx,t,[3,3.16,3.2,3.45],
 (layer,at)=>drawOriginal(layer,at),
 (layer,at)=>drawTranslation(layer,at));
```

四个绝对时刻分别是旧内容退场起点、清空、开始显露、显露完成；要求 `start < clear <= show < end`。旧内容在起点之前保持完整，新内容在终点之后保持完整；清空区间两者都不画，同一帧最多调用一侧，避免同位置交叉淡化。回调继承父级 alpha/变换并在返回或异常时恢复。返回 `{phase,opacity}`，phase 为 before/clear/after；它不自动测量遮挡、裁切阅读区、修改字幕或决定语义事件，也不应用于本来需要并排对照的内容。

全片验证既要看关键帧，也要覆盖快速运动与落定后的连续片段。几何可辨、接触遮挡和可读性优先；有限投影与乱序绘制检查不能证明广告效果或真实物理。


快速运动可用 `ProductMotion.trail(ctx,t,[start,end],drawSubject,{samples:4,shutter:.06,opacity:.16})`：drawSubject(ctx,sampleTime) 只画当前运动主体，必须纯时间求值；助手先画少量历史姿态再画当前姿态，保留父级 alpha 和变换。它是短拖影，不是物理快门或全场景运动模糊。停留段不会残留；文字与真实 UI 通常单独绘制，避免重影损害可读性。
