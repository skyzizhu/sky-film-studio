# 微信小程序 · 从 0 到上架，7 步 —— 60s 电影感知识短片

**成片**：`out/wxminipro_60s_1080p30.mp4`（1920×1080 / 30fps / 60.000s / H.264 + AAC 44.1kHz 立体声 / 14.3MB）

## 一、制作管线（代码生成视频）

```
data.js（数字唯一来源）
   └→ index.html + lib.js + scenes_a.js + scenes_b.js + main.js
        window.draw(t)：画面完全由 t 决定（无 rAF / Date / 无种子随机）
   └→ render.py（Playwright Chromium，字体加载完成才开始；导出 jpeg 帧）
        静帧自查 3 轮（13 关键帧 + 8 中间态 + 成片抽帧）→ 修复 3 轮
        全片 1800 帧导出（66s）
audio.py（numpy 纯合成，种子固定）
   100 BPM / 4/4，每小节 2.4s，25 小节 = 60s；BGM 段落强弱按分镜；全部音效与画面动效逐点对齐；
   总线 tanh 软限幅 + 归一化峰值 -1dB（实测 RMS 0.20→0.32 渐强，55-60s 淡出）
   └→ audio/mix.wav
ffmpeg -framerate 30 -i frames/f%05d.jpg -i audio/mix.wav
   -c:v libx264 -crf 17 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart
```

## 五、复现

```bash
python3 render.py --full          # 1800 帧导出
python3 audio.py                  # 音频合成
ffmpeg -y -framerate 30 -i frames/f%05d.jpg -i audio/mix.wav \
  -c:v libx264 -crf 17 -pix_fmt yuv420p -c:a aac -b:a 192k \
  -shortest -movflags +faststart out/wxminipro_60s_1080p30.mp4
```

确定性保证：同一 t 渲染两次逐像素一致（颗粒瓦片按帧号轮换、粒子/噪声全部种子化、无 Date/random/rAF）。
